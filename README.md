# SGRADER UP demo

Статическая демо-игра с общей авторизацией, профилями игроков, апгрейдом с несколькими скинами в ставке и общими батлами на Supabase. Каталог включает оружейные скины, ножи, перчатки, стикеры, агентов, граффити и музыкальные наборы CS2. Записанные изображения — игровые превью CS2, а не старые картинки CS:GO; набор категорий и число предметов указаны в [`catalog-source.json`](catalog-source.json).

Данные каталога берутся из публичного [CS2Cap/CS2-API](https://github.com/CS2Cap/CS2-API), собранного из файлов CS2; свежесть видна в `catalog-source.json`. Его лицензия приложена в [`CS2-API-LICENSE.txt`](CS2-API-LICENSE.txt). Для обновления файлов из корня проекта запусти `./refresh-cs2-catalog.ps1`; скрипт обновляет JSON и снимок источника как в корне сайта, так и в `deploy-site/`. Релизы коллекций и турниров отображаются в каталоге как фильтр «Новинки <текущий год>». Предметы показываются с игровыми CS2-превью, метками редкости и года выпуска. Цены внутри игры остаются условными демо-ценами, это не цены торговой площадки.

В батлах ставка гостя должна быть не меньше 95% цены скина создателя; условие проверяет база. Инструкция подключения базы находится в [`supabase/README.md`](supabase/README.md), схема — в [`supabase/schema.sql`](supabase/schema.sql), обновляемая миграция для уже подключённой базы — в [`supabase/skin-battles.sql`](supabase/skin-battles.sql).

Баланс отображается знаком ₽ только для игры. Это вымышленные демо-рубли: сайт не принимает оплату, не выдаёт реальные деньги или предметы. Администратор может начислять и снимать демо-рубли; списание не может опустить баланс ниже нуля. Исход батла выбирается сервером с шансом 50/50.

Не загружайте в `supabase-config.js` ключ `service_role`. Нужен только публичный publishable/anon key, защищённый RLS-политиками из SQL-схемы.
