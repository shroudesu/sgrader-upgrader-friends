# SGRADER UP

Статическая игра с общей авторизацией, профилями игроков, апгрейдом с несколькими скинами в ставке и общими батлами на Supabase. Каталог охватывает оружейные скины, ножи, перчатки, стикеры, агентов, граффити и музыкальные наборы из игрового источника CS2. Оружейные finish-варианты перечислены отдельно по износу, StatTrak и Souvenir. Числа по категориям и дата обновления находятся в [`catalog-source.json`](catalog-source.json).

Данные берутся из публичного [CS2Cap/CS2-API](https://github.com/CS2Cap/CS2-API), собранного из файлов CS2; свежесть видна в `catalog-source.json`. Его лицензия приложена в [`CS2-API-LICENSE.txt`](CS2-API-LICENSE.txt). Для обновления файлов из корня проекта запусти `./refresh-cs2-catalog.ps1`; скрипт обновляет JSON и снимок источника в корне сайта и в `deploy-site/`. Каталог показывает игровые превью, качество/износ, редкость, эффекты и год выпуска. Цена — игровая расчётная оценка с вариантами по редкости, износу, StatTrak, Souvenir и эффектам, а не котировка с LIS-Skins или Steam.

Список покрывает модели и варианты, опубликованные источником данных игры. Уникальные параметры конкретных торговых лотов (seed паттерна, фактический float, нанесённые стикеры и актуальная цена) не являются отдельными моделями в этом источнике и не импортируются.

В батлах каждый участник может поставить от одного до пяти скинов. Суммарная ставка гостя должна быть не меньше 95% суммарной ставки создателя; условие и равный шанс 50/50 проверяет база. После обновления фронтенда нужно повторно выполнить [`supabase/skin-battles.sql`](supabase/skin-battles.sql) в SQL Editor проекта Supabase, чтобы включить новый RPC для наборов скинов. Управление инвентарём игрока из админ-панели требует выполнить [`supabase/admin-inventory.sql`](supabase/admin-inventory.sql). Инструкция подключения базы находится в [`supabase/README.md`](supabase/README.md), схема — в [`supabase/schema.sql`](supabase/schema.sql).

Баланс отображается в выбранной валюте RUB/USD; конвертация в интерфейсе использует фиксированное соотношение 1 USD = 90 RUB. Пополнение открывает заготовленное сообщение администратору и само по себе не проводит платёж. Администратор может начислять и снимать баланс; списание не может опустить его ниже нуля. Исход батла выбирается сервером с шансом 50/50.

Не загружайте в `supabase-config.js` ключ `service_role`. Нужен только публичный publishable/anon key, защищённый RLS-политиками из SQL-схемы.
