# SGRADER UP demo

Статическая демо-игра с общей авторизацией, профилями игроков, апгрейдом с несколькими скинами в ставке и общими батлами на Supabase. В батлах ставка гостя должна быть не меньше 95% цены скина создателя; условие проверяет база. Инструкция подключения базы находится в [`supabase/README.md`](supabase/README.md), схема — в [`supabase/schema.sql`](supabase/schema.sql), обновляемая миграция для уже подключённой базы — в [`supabase/skin-battles.sql`](supabase/skin-battles.sql).

Баланс отображается знаком ₽ только для игры. Это вымышленные демо-рубли: сайт не принимает оплату, не выдаёт реальные деньги или предметы. Администратор может начислять и снимать демо-рубли; списание не может опустить баланс ниже нуля. Исход батла выбирается сервером с шансом 50/50.

Не загружайте в `supabase-config.js` ключ `service_role`. Нужен только публичный publishable/anon key, защищённый RLS-политиками из SQL-схемы.
