# SGRADER UP demo

Статическая демо-игра с общей авторизацией, профилями игроков, апгрейдом, мультивыбором ставок и общими батлами скинов на Supabase. Инструкция подключения базы находится в [`supabase/README.md`](supabase/README.md); SQL-схема — в [`supabase/schema.sql`](supabase/schema.sql), миграция батлов для уже подключённой базы — в [`supabase/skin-battles.sql`](supabase/skin-battles.sql).

Баланс отображается знаком ₽ только для игры. Это вымышленные демо-рубли: сайт не принимает оплату, не выдаёт реальные деньги или предметы. Исход батла рассчитывается сервером с шансом 50/50.

Не загружайте в `supabase-config.js` ключ `service_role`. Нужен только публичный publishable/anon key, защищённый RLS-политиками из SQL-схемы.
